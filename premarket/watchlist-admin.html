⚙️ 追蹤清單管理

新增／刪除盤前快報固定追蹤的台股與美股標的，直接寫回 GitHub repo，明天報告自動套用。

🔑 GitHub 連線

需要一組 Fine-grained Personal Access Token，只給這個 repo 的「Contents: Read and write」權限即可，不要給其他權限。Token 只會存在你這台裝置的瀏覽器（localStorage），不會出現在網頁原始碼或其他地方。

  1. 開啟 github.com/settings/personal-access-tokens/new
  2. Repository access 選「Only select repositories」→ 勾選 titankou2002/sleeping-beauty-bonus
  3. Permissions → Repository permissions → Contents 設為 Read and write（其他保持 No access）
  4. Generate token，複製後貼到下面
